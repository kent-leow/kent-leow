### **Project: Interactive Modern Personal Portfolio Website**

#### **Objective**

Build a professional, visually appealing, and interactive personal website to serve as a live résumé and showcase of skills, with a strong focus on modern UI/UX and responsive design.

---

### **User Requirements**

| **ID** | **Requirement**                | **Details**                                                                                                                                               |
| ------ | ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| UR1    | **Live Resume Website**        | Design a personal website to act as a digital resume: intro, skills, experience, projects, contact.                                                       |
| UR2    | **Modern & Minimalist Design** | Sleek, high-end design theme inspired by tech/code (e.g., terminal vibes, grid, geometric layout, etc.).                                                  |
| UR3    | **Animated Background**        | Use minimalistic, tech-inspired animated background that enhances visual appeal without distracting from content.                                         |
| UR4    | **Interactive Animations**     | - Animate on **mouse scroll** (desktop)<br>- Animate on **drag gesture** (mobile)<br>- Use parallax, transform, or morphing effects creatively.           |
| UR5    | **Responsive Design**          | Fully responsive across all devices:<br>- Desktop<br>- Tablets<br>- Mobile phones<br>Layouts adjust to screen sizes fluidly.                              |
| UR6    | **Interactive UI**             | Enable user interaction with elements (e.g., expanding cards, tooltips, toggles, lightboxes, etc.) instead of static text.                                |
| UR7    | **Dynamic Text Appearance**    | Prevent long sticky blocks of text. Content should:<br>- Summarize key info<br>- Reveal progressively while scrolling<br>- Use motion to keep engagement. |
| UR8    | **No Boring Sections**         | Avoid conventional long pages. Prefer dynamic sections with scroll-based transitions or cards/sections that come alive.                                   |

---

### **User Experience (UX) Goals**

* Smooth transitions and fluid interactions.
* Engaging visual storytelling without overwhelming the user.
* Clarity of information with minimal friction to navigate.
